
# Library Management System

## Project Overview
A Python-based library management system for managing books and registered users, including book borrowing and returning.

## Features
- Add and list books
- Register, update, list, and delete users
- Borrow and return books
- Track book availability and borrowing status
- Validate borrowing and return operations

## Technologies
- Python
- Object-Oriented Programming (OOP)
- Lists and Dictionaries
